# learningjs

A hands-on JavaScript learning repository with small projects and topic-based practice files.

## Featured Projects
- **Focus-on-today**: Daily focus/task tracker UI with DOM updates and interactions.
	- Live: https://focus-on-taday.netlify.app
- **DOM Practice Modules**: append/appendChild, createElement, delegation, bubbling/capturing, listeners, keyboard/mouse events.
- **ES6Features**: modern JavaScript syntax and patterns.
- **Event Loop & Callback Queue**: async behavior practice.

## Core Topics Covered
- DOM and BOM
- Events and event handling
- Arrays and objects
- Higher-order functions
- Important methods (`forEach`, `map`, `filter`, `reduce`)
- LocalStorage
- setTimeout and setInterval

## Purpose
Build JavaScript fundamentals by creating and testing mini-projects, not just reading theory.
